# Amazon Clone 🛒

A fully responsive **Amazon website clone** built with **HTML, CSS, and Font Awesome**.  
This project is created for **learning front-end web development** by replicating the design and functionality of a real e-commerce website.

---

## 🌟 Features

- Responsive navigation bar with logo, delivery location, search bar, and cart icon
- Product sections with categories:
  - Musical Devices
  - Gaming
  - Toys
  - Fashion & Accessories
  - Cosmetics
- Gift sections by recipient: For him, her, kids, teens
- Discounted deals sections: Electronics, Home & Kitchen, Fashion
- Footer similar to Amazon with multiple links
- Hover effects, background images, and clean layout

---

## 💻 Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout  
- **Font Awesome** – Icons  
- **Responsive Design** – Works on desktop and mobile
